# Kiroween 2026 submission requirements (Resurrection)

- A working public URL over HTTPS that works offline after the first visit.
- A public GitHub repo with all source and instructions, and an MIT LICENSE that GitHub shows in the About section.
- /.kiro at the repo root (specs, steering, hooks), never in .gitignore.
- A demo video under 3 minutes, public on YouTube, showing the app on a phone, no copyrighted music.
- A text description and the "how Kiro was used" write-up, in English. Category: Resurrection.
- Bonus: Best Demo (automatic); Blog (published during the period, says it is part of Kiroween 2026);
  Social Blitz (post starting with #KiroweenHackathon26, written by the user); only if true: Ghost of Kiroween
  Past, Startup, Student; Kiro Crew App only as a separate new repo.
- Deadline 4 Dec 2026, 2:00 pm PT. `npm test` and `npm run build` must pass from a fresh clone.
