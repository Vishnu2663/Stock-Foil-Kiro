# Stock & Foil

The tally sticks that burned Parliament have come back from the dead.

Stock & Foil is a tamper-proof paper work record for people paid daily in cash. A card prints in two halves
separated by a unique wavy cut. The worker keeps the stock, the employer keeps the foil, and both are punched
together every day. On payday a phone camera scans both halves, proves they belong together, counts the days and
prints a picture pay slip. Free, offline, no server, no account.

Built with Kiro for the Kiroween 2026 hackathon (Resurrection category). Work in progress.

## Run

    npm install
    npm run dev
    npm test
    npm run build

The full build brief is in [docs/BUILD_BRIEF.md](docs/BUILD_BRIEF.md). Kiro specs, steering and hooks are in [.kiro/](.kiro/).
